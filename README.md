# pvault
Offline encrypted file vault with portable and TPM-bound modes.

> **Status: development preview, not production-ready.** Not released and
> not independently audited. Milestone 5 is accepted as emulator-tested work
> only; Milestone 4 is implemented but **not accepted**, and its manual
> acceptance gates are outstanding. Bound (TPM) mode has been tested only on
> the `swtpm` emulator and needs real-hardware validation before any
> release. Do not use it to protect real data.
