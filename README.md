# pvault
Offline encrypted file vault with portable and TPM-bound modes.

> **Status: development preview, not production-ready.** Not released and
> not independently audited. Milestones 4 and 5 are implemented but **not
> accepted**; manual acceptance gates are outstanding. Bound (TPM) mode has
> been tested only on the `swtpm` emulator and needs real-hardware
> validation before any release. Do not use it to protect real data.
